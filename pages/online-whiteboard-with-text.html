Three Ways to Add Text to Your Whiteboard

Each method has different strengths — use them together for richer canvases.

Text Tool (typed, fixed): Click the text tool, click anywhere on the canvas, and type. The text is rendered cleanly in a standard font with selectable size and colour. Best for labels on diagrams, headings, slide titles, and any text that must be clearly legible at a distance or in exports.

Pen Tool (handwritten, expressive): Draw letters and words with the pen, calligraphy, or highlighter tool for a handwritten look. Best for annotations that should feel personal — teacher corrections, design feedback, or notes that stand out from the diagram itself.

Sticky Notes (typed, moveable): Sticky notes contain their own text fields. Type inside the note, then drag it anywhere on the canvas. Best for brainstorming, KWL charts, kanban columns, and any scenario where text needs to be repositioned freely.

Combination approach: Use typed text tool labels for diagram components, handwritten pen annotations for corrections and emphasis, and sticky notes for ideas that may need to be reorganised. Together they cover every whiteboard text use case.

How to Add Text to Your Whiteboard

Choose your text method and start in seconds.

1

Open the Whiteboard

Go to onlinewhiteboard.org. No account. The canvas loads with the full toolbar visible — text tool, pen, and sticky notes are all in the toolbar.

2

Select Your Text Method

For typed text: click the T (text) tool, click on the canvas, and type. For sticky notes: click the sticky note icon, click on the canvas, and type inside it. For handwriting: select the pen or calligraphy tool and write directly.

3

Style and Export

Change font size and colour in the toolbar options. Drag sticky notes to reposition. When done, click PDF to export with all text included cleanly.

Frequently Asked Questions

Can I change the font size of text on the whiteboard?

Yes — select the text tool and choose the font size from the toolbar options before or after placing text on the canvas.

Can I type in any language on the whiteboard?

Yes — the text tool accepts any language and script supported by your device keyboard. Handwriting with the pen tool works for any script including CJK characters.

Does text export clearly in the PDF?

Yes — typed text renders as clean vector text in the PDF output. Sticky note text also exports clearly. Handwritten pen text exports as drawn paths, which look exactly as they appear on the canvas.

Can I move text after I have typed it?

Sticky notes can be moved freely by dragging. Text tool text can be selected and repositioned. Use the selection tool to click and drag text elements.

Can I mix handwriting and typed text on the same canvas?

Yes — use all three text methods on the same canvas. There are no restrictions on combining typed labels, sticky notes, and handwritten pen annotations.

Is there a text size limit?

There is no character limit. Type as much text as needed in sticky notes or text boxes. The canvas expands infinitely to accommodate all content.
